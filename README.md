# Football Team Site

A responsive static promotional website built with React and Vite.

## Run locally

```bash
npm install
npm run dev
```

Open the local address shown in your terminal.

## Build for deployment

```bash
npm run build
```

The production files will be created in `dist/`.

## Personalize it

Start with:

- `src/data/teamData.js` — team name, players, fixtures, results and stats
- `src/styles.css` — colors, typography and layout
- `src/App.jsx` — page sections and text
- `index.html` — page title and description

To add a real team photograph, place it inside `public/`, then replace the placeholder in the Story section with an `<img>` element.
